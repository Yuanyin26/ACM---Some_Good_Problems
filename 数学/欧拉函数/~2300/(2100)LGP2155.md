## P2155 [SDOI2008] 沙拉公主的困惑

[P2155 [SDOI2008\] 沙拉公主的困惑 - 洛谷](https://www.luogu.com.cn/problem/P2155)

## 思路

将 $N!$ 按照块大小 $M!$ 划分，这样每一块在与 $M!$ 互质方面是等价的。可得公式 $\frac{N!}{M!}\phi(M!)$ ，然后将欧拉函数用通项公式展开，预处理所需要的值，然后计算即可。

注意特判能被 $R$ 整除的数。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 1e7 + 7;
constexpr int P = 1e9 + 7;
//筛素数
std::deque<int>pri;
bool vis[N];
int minp[N];//存数的最小质因子
int fa[N],inv[N];
int pre[N];
void init(int p)
{
    fa[1] = fa[0] = 1;inv[1] = 1;
    for(int i = 2;i < N;i++)
    {
        if(i % p)
        {
            inv[i] = (p - p / (i % p)) * inv[p % (i % p)] % p;
            fa[i] = fa[i - 1] * i % p;
        }
        else
        {
            inv[i] = inv[i - 1];
            fa[i] = fa[i - 1];
        }

        if(!vis[i]){pri.push_back(i);minp[i] = i;}
        for(auto x : pri)
        {
            if(i * x >= N)break;
            vis[i * x] = 1;
            minp[i * x] = x;
            if(i % x == 0)break;
        }
    }
    pri.push_front(1);
    pre[0] = 1;
    for(int i = 1;i < pri.size();i++)
    {
        int INV = pri[i] != p ? inv[pri[i]] : 1; 
        pre[i] = (pri[i] - 1) * INV % p * pre[i - 1] % p;
    }
}
void solve()
{
    int t,R;
    std::cin >> t >> R;
    init(R);
    for(int i = 0;i < t;i++)
    {
        int n,m;
        std::cin >> n >> m;
        if(n >= 2 * R || (n >= R && m < R))std::cout << "0\n";
        else
        {
            int pos = std::upper_bound(pri.begin(),pri.end(),m) - pri.begin() - 1;
            int ans = fa[n] * pre[pos] % R;
            std::cout << ans << "\n";
        }

    }
    
}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
