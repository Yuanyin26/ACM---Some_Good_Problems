## P6615 草莓 Strawberry

[P6615 草莓 Strawberry - 洛谷](https://www.luogu.com.cn/problem/P6615)

## 思路

首先直径有一个性质：任意节点与其他节点路径的最大值来源于直径的两个端点之一。

对于任何一个选择的点集，我们都可以将直径两个端点加入，然后通过走最大的这个路径来加入所有这些点集，最后构造的边集最小值一定是比原本的边集要好。

我们得出每个点出发能走的最长路径并排序，前两个点构成直径的两个端点，然后边加入点边更新答案即可。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 3e5 + 7;
constexpr int P = 99824435;
using ull = unsigned long long;
using ld = long double;
struct edge
{
    int nx;
    int to;
    int w;
}e[N << 1];int heads[N],cntqq = 0;
void add(int u,int v,int w)
{
    e[++cntqq] = {heads[u],v,w};
    heads[u] = cntqq;
}
void solve()
{
    int n;std::cin >> n;
    std::vector<pii>a(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> a[i].second;
    for(int i = 1;i < n;i++)
    {
        int u,v,w;
        std::cin >> u >> v >> w;
        add(u,v,w);
        add(v,u,w);
    }

    std::vector<int>dep(n + 1);
    int st = 1,ed = 1;
    auto dfs = [&](auto &&self,int u,int fa,int deep,int &pos) -> void
    {
        dep[u] = deep;
        if(dep[u] > dep[pos])pos = u;
        for(int i = heads[u];i;i = e[i].nx)
        {
            int v = e[i].to,w = e[i].w;
            if(v == fa)continue;
            self(self,v,u,deep + w,pos);
        }
    };
    dfs(dfs,1,0,0,st);
    dfs(dfs,st,0,0,ed);
    auto dfs1 = [&](auto &&self,int u,int fa,int len) -> void
    {
        a[u].first = std::max(dep[u],len);
        for(int i = heads[u];i;i = e[i].nx)
        {
            int v = e[i].to,w = e[i].w;
            if(v == fa)continue;
            self(self,v,u,len + w);
        }
    };
    dfs1(dfs1,ed,0,0);
    std::sort(a.begin() + 1,a.end());
    std::reverse(a.begin() + 1,a.end());
    int ans = 0,sum = 0;
    for(int i = 1;i <= n;i++)
    {
        auto [len,w] = a[i];
        sum += w;
        ans = std::max(ans,sum * len);
    }
    std::cout << ans << "\n";
}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
