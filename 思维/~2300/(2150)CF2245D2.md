# D2. Construct an Array (Hard Version)

[Problem - D2 - Codeforces](https://codeforces.com/contest/2245/problem/D2)

## 思路

假设当前存在一种合法状态。对于目前的一个绝对值的最大值 $M$ 及其编号 $u$，绝对不存在两种类型的连边。如果连边为类型 $1$，那么可令 $a[u]$ 是一个正数，否则 $a[u]$ 是一个负数。此时这个节点的相关限制一定能被保证，我们将其删掉。按照这种方式，我们一定能删掉所有的边。

同样我们按照这种方式构造：选择一个连边类型只有一种的节点，将其值的绝对值设置为 $M$，符号由连边类型确定。然后将这个点相关的边删掉，剩余节点取值上限设置为 $M - 1$。然后继续这样做即可。

此时如果无法删掉所有的节点，说明无解。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n,m;std::cin >> n >> m;
    std::vector<int>a(n + 1);
    std::vector du(n + 1,std::vector<int>(2));
    std::vector<std::vector<pii>>g(n + 1);
    for(int i = 1;i <= m;i++)
    {
        int o,u,v;
        std::cin >> o >> u >> v;
        o--;
        g[u].push_back({v,o});
        g[v].push_back({u,o});
        du[u][o]++;
        du[v][o]++;
    }
    std::queue<int>que;
    std::vector<int>ans(n + 1),vis(n + 1);
    for(int i = 1;i <= n;i++)
    {
        if(!du[i][0] || !du[i][1])
        {
            que.push(i);
            vis[i] = 1;
            if(!du[i][0])ans[i] = -n;
            else ans[i] = n;
        }
    }
    while(!que.empty())
    {
        int u = que.front();que.pop();
        for(auto [v,op] : g[u])
        {
            if(vis[v])continue;
            du[v][op]--;
            if(!du[v][op])
            {
                que.push(v);
                vis[v] = 1;
                int val = std::llabs(ans[u]) - 1;
                if(!op)ans[v] = -val;
                else ans[v] = val;
            }
        }
    }
    if(std::count(vis.begin() + 1,vis.end(),0))std::cout << "No\n";
    else
    {
        std::cout << "Yes\n";
        for(int i = 1;i <= n;i++)
            std::cout << ans[i] << " \n"[i == n];
    }


}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
