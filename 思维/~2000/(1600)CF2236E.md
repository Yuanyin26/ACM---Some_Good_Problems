# E. Friendly Gifts

[Problem - E - Codeforces](https://codeforces.com/contest/2236/problem/E)

## 思路

注意到题目需求合法的数组有一个满足条件：

如果 $mx - mn + 1 == len$，且无重复数字

那么这个数组合法(根据最小值 $mn$ 和长度 $len$ 来区分不同合法情况)。

将所有合法情况标记，然后遍历所有可能的数组组合。如果组合的两个数组都被标记，说明此情况存在。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e4 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n;
    std::cin >> n;
    std::vector<int>a(n + 1);
    std::vector<std::vector<bool>>flag(n + 1,std::vector<bool>(n + 1));
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    for(int l = 1;l <= n;l++)
    {
        std::vector<bool>vis(n + 1);
        int mn = inf,mx = -inf,len = 0;
        for(int r = l;r <= n;r++)
        {
            len++;
            mn = std::min(mn,a[r]);
            mx = std::max(mx,a[r]);
            if(vis[a[r]])break;
            vis[a[r]] = 1;
            if(mx - mn + 1 == len)flag[len][mn] = 1;
        }
    }
    for(int i = n;i >= 1;i--)
    {
        for(int j = 1;j + i <= n;j++)
        {
            if(flag[i][j] && flag[i][j + i])
            {
                std::cout << i << "\n";
                return;
            }
        }
    }
    std::cout << "0\n";
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
