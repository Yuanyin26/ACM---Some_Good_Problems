# C2. Interactive Graph (Hard Version)

[Problem - C2 - Codeforces](https://codeforces.com/contest/2196/problem/C2)

## 思路

从一个单节点路径 $u$ 开始，其下一个路径要么是其第一条出边，要么当前节点没有路径，指向下一个节点。

考虑有出边的情况，假设其指向 $v$，以此路径为起点 $st$，有一段连续的路径区间，其中所有路径都是以 $u\rightarrow v$ 为起点的，数量等于以 $v$ 为起点的路径数量。设 $cnt_u$ 代表以 $u$ 为起点的路径数量，那么 $u$ 的下一条出边的位置应该在 $st + cnt[v]$。由于题目给定是一个 $DAG$，我们可以递归下去先得到 $cnt_v$ ，当我们下次需要 $cnt_v$ 时，直接用即可。这样只需查询 $n + m$ 次。

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
void solve()
{
    int n;std::cin >> n;
    auto query = [&](int k) -> std::vector<int>
    {
        std::cout << "? " <<  k << std::endl;
        int q;std::cin >> q;
        if(q == -1)exit(0);
        std::vector<int>ans({});
        for(int i = 1;i <= q;i++)
        {
            int x;std::cin >> x;
            ans.push_back(x);
        }
        return ans;
    };
    std::vector<pii>edge;
    std::vector<int>cnt(n + 1),vis(n + 1);
    auto dfs = [&](auto &&self,int u,int ind,int pos) -> void
    {
        vis[u] = 1;
        cnt[u] = 1;
        for(int nx = ind + 1;;)
        {
            std::vector<int>que = query(nx);
            if(que.size() <= pos)break;
            int v = que[pos];
            edge.push_back({u,v});
            if(!vis[v])
                self(self,v,nx,pos + 1);
            nx += cnt[v];
            cnt[u] += cnt[v];
        }
    };
    for(int i = 1,pre = 0;i <= n;i++)
    {
        if(!vis[i])dfs(dfs,i,pre + 1,1);
        pre = pre + cnt[i];
    }
    std::cout << "! " << edge.size() << std::endl;
    for(auto [u,v] : edge)
        std::cout << u << " " << v << std::endl;
}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
