# E. Count Paths

[Problem - E - Codeforces](https://codeforces.com/contest/1923/problem/E)

## 思路

固定根节点，考虑所有合法的路径 $u,v$ ，只有两种情况，$LCA(u,v)$ 等于 $u$ 或者 $v$，和除开 $u,v$ 之外的节点。对于这个节点 $lc$，分别考虑这两种情况，然后更新需要维护的状态即可。我们采用启发式合并的方式来降低复杂度。 

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n;std::cin >> n;
    std::vector<int>c(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> c[i];
    std::vector<std::vector<int>>g(n + 1);
    for(int i = 1;i < n;i++)
    {
        int u,v;
        std::cin >> u >> v;
        g[u].push_back(v);
        g[v].push_back(u);
    }
    int ans = 0;
    std::vector<std::unordered_map<int,int>>dp(n + 1);
    auto dfs = [&](auto &&self,int u,int fa) -> void
    {
        for(int v : g[u])
        {
            if(v == fa)continue;
            self(self,v,u);
            if(dp[u].size() < dp[v].size())std::swap(dp[u],dp[v]);
            for(auto [col,cnt] : dp[v])
            {
                if(col != c[u])ans += dp[u][col] * cnt;
                dp[u][col] += cnt;
            }
        }
        ans += dp[u][c[u]];
        dp[u][c[u]] = 1;
    };
    dfs(dfs,1,0);
    std::cout << ans << "\n";
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
