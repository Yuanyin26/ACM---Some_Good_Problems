## P3435 [POI 2006] OKR-Periods of Words

[P3435 [POI 2006\] OKR-Periods of Words - 洛谷](https://www.luogu.com.cn/problem/P3435)

## 思路

对于一般的 **KMP**，我们都是找最长的相等的真前缀和真后缀，而这题我们只需要找到最小的相等的真前缀和真后缀，然后字符串长度减去这个值就是字符串的最长周期，当这个值为 $0$ 时说明周期为 $0$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f

#define int long long
using i64 = long long;

using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;

void solve()
{
    int n;std::cin >> n;
    std::string s;std::cin >> s;
    std::vector<int>pi(n),mn(n);
    int ans = 0;
    for(int i = 1;i < n;i++)
    {
        int pos = pi[i - 1];
        while(pos && s[pos] != s[i])pos = pi[pos - 1];
        if(s[pos] == s[i])pos++;
        pi[i] = pos;
        if(!pos || !pi[pos - 1])mn[i] = pos;
        else if(!mn[pi[pos - 1] - 1])mn[i] = pi[pos - 1];
        else mn[i] = mn[pi[pos - 1] - 1];
        if(mn[i])
            ans += (i + 1) - mn[i];
        
    }
    std::cout << ans << "\n";
}

signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
