## P4824 [USACO15FEB] Censoring S

[P4824 [USACO15FEB\] Censoring S - 洛谷](https://www.luogu.com.cn/problem/P4824)

## 思路

对 $T + $"#" 构造前缀函数数组，枚举 **S** 拼接上去并算前缀函数，如果长度等于 |**T**|，说明匹配成功，将这部分弹出。最后剩余的字符串就是答案。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);

void solve()
{
    std::string s,t;

    int n = t.size(),m = s.size();
    t = t + "#";
    std::vector<int>pi(n + 1);
    for(int i = 1;i <= n;i++)
    {
        int ind = pi[i - 1];
        while(ind && t[ind] != t[i])ind = pi[ind - 1];
        if(t[ind] == t[i])ind++;
        pi[i] = ind;
    }
    std::stack<pii>stk;stk.push({pi[n],-1});
    for(int i = 0;i < m;i++)
    {
        int ind = stk.top().first;
        while(ind && t[ind] != s[i])ind = pi[ind - 1];
        if(t[ind] == s[i])ind++;
        if(ind != n)stk.push({ind,i});
        else
            for(int j = 1;j < n;j++)stk.pop();

    }
    auto dfs = [&](auto &&self) -> void
    {
        if(!stk.empty())
        {
            auto [x,ind] = stk.top();stk.pop();
            if(ind != -1)
            {
                self(self);
                std::cout << s[ind];
            }
        }
    };
    dfs(dfs);

}

signed main()
{

    while(T--)
    {
        solve();
    }

}
```
