# D. Om Nom and Necklace

[Problem - D - Codeforces](https://codeforces.com/contest/526/problem/D)

## 思路

求出 **KMP** 即可得到最小周期 **S**。将 **AB** 看作整体，则 **AB** 也应该是 **S** 的一个周期。那么 **AB** 的长度可以设置为 **g**|**S**|。因为需要 **K** 段 **AB**，所以可以得到 **g** 的取值，此时剩余的 **S** 段与不完全的末尾段连接，成为 **A**。那么显然，连接的部分长度小于等于 **g**|**S**|时，即满足题目要求的序列。

#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f

#define int long long
using i64 = long long;

using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;

void solve()
{
    int n,k;
    std::cin >> n >> k;
    std::string s;std::cin >> s;
    std::vector<int>pi(n);
    std::cout << (int)(k == 1);
    for(int i = 1;i < n;i++)
    {
        int pos = pi[i - 1];
        while(pos > 0 && s[pos] != s[i])pos = pi[pos - 1];
        if(s[pos] == s[i])pos++;
        pi[i] = pos;
        int t = 1 + i - pi[i];
        int cnt = (i + 1) / t;//最小周期数量
        int ct = cnt / k;//每个最多放多少个周期
        int res = cnt % k;//剩余的周期
        bool op = ct >= res;
        if((i + 1) % t && ct == res)op = 0;
        std::cout << (int)op;
    }
}

signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
