# D. Good Schedule

[Problem - 2230D - Codeforces](https://codeforces.com/problemset/problem/2230/D)

## 思路

$DP$ 当前结尾为 $i$ ，Alice 和 Bob 已经看过节目 $1$ ~ $j$ 的区间数。$j = 0$ 代表一个节目都还没看。

当前位置两人的节目都为 $x$ 时，$dp[i - 1][x - 1]$ 的所有方案数下，两人会观看节目 $x$，这些方案数都加到 $dp[i][x]$ 上，并将 $dp[i][x - 1]$ 赋值为 $0$ ，同时该位置可以单开一个区间；

当节目不同时，对两个位置 $-1$ 的方案数都得归 $0$ 。当两个位置都不为 $1$ 时，可以单开一个区间方案数。

这样更新的时候，每次移动变化的值都是常数级别的，记录一个当前总值，每次更新完后算答案贡献即可。

#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f

#define int long long

using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n;
    std::cin >> n;
    std::vector<int>a(n + 1),b(n + 1),dp(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    for(int i = 1;i <= n;i++)std::cin >> b[i];
    int now = 0,ans = 0;
    for(int i = 1;i <= n;i++)
    {
        if(a[i] == b[i])
        {
            dp[a[i]] += dp[a[i] - 1];
            dp[a[i] - 1] = 0;
            if(a[i] == 1){dp[1]++;now++;}
            else {dp[0]++;now++;}
        }
        else
        {
            now -= dp[a[i] - 1] + dp[b[i] - 1];
            dp[a[i] - 1] = dp[b[i] - 1] = 0;
            if(a[i] != 1 && b[i] != 1){dp[0]++;now++;}
        }
        ans += now;
    }
    std::cout << ans << "\n";
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
