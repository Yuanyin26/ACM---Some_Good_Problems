# A. 小 X 今天心情怎么样？

[小 X 今天心情怎么样？ - 题目 - QOJ.ac](https://qoj.ac/contest/3945/problem/19013)

## 思路

首先每天可以有两种状态：回复周期启动和未启动。

假设当前周期已经启动，因为要使焦虑值最小，所以对于一天中所有的 $a$ 条消息，做出的动作应该是一致的（因为他们选择发送产生的焦虑值相同、选择不发送产生的也相同，他们都会取更小的那部分）；

假设当前周期未启动，两种情况：都选择不发送，或者一条消息发送，此时启动周期，然后 $a - 1$ 条消息接着选择相同的产生焦虑值更小的那部分。

我们可以 $dp$ 这个过程，定义 $dp_{ij}$ ，如果 $j = 0$，表示当前处于未启动阶段，$j = 1$ ~ $d$ 代表当前处于启动周期时的第多少天。由于启动周期后，再经过 $d$ 天时，此时应该把所有未发送的邮件全部发送，他们之后不会产生贡献，所以 $dp_{i1}$ 的更新需要向前枚举；其他 $j$ 只需要上一个位置的更新即可 $j = 0$ 可以由 $j = 0,d$ 转移过来。

 

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
int calc(int x, int y)
{
    if(x > y)return 0;
    int len = y - x + 1;
    return x * len + len * (len - 1) / 2;
}
void solve()
{
    int n, a, b, c1, c2, d;
    std::cin >> n >> a >> b >> c1 >> c2 >> d;
    
    d = std::min(5050LL, d);
    std::vector dp(n + 1, std::vector<int>(d + 1, INF));
    dp[0][0] = 0;

    for (int i = 1; i <= n; i++)
    {
        dp[i][0] = std::min(dp[i - 1][d],dp[i - 1][0] + a * c1 * std::min(n - i + 1,b));

        int A = c2 * std::min(d, n - i + 1);
        int B = c1 * std::min({b, n - i + 1, d});

        for (int j = 0; j < i; j++)
        {
            int sum = dp[j][0] + std::min(d, n - i + 1) * c2 + std::min(A, B) * (a - 1);

            int tmp = 0, ed = std::min(n, i + d - 1);
            int x = ed - b + 1;
            int len = (i - 1 - j - 1 + 1);
            int len1 = (i - 1 - x + 1);

            if (j + 1 <= i - 1)
            {
                if (x < j + 1)
                    tmp = (len * (ed + 1) - calc(j + 1, i - 1)) * a * c1;
                else if (x >= i - 1)
                    tmp = len * b * a * c1;
                else
                {
                    tmp = (len1 * (ed + 1) - calc(x, i - 1) + b * (len - len1)) * a * c1;
                }
            }

            dp[i][1] = std::min(dp[i][1], sum + tmp);
        }

        for (int j = 2; j <= d; j++)
        {
            int tpA = c2 * std::min({d - j + 1, n - i + 1});
            int tpB = c1 * std::min({b, n - i + 1, d - j + 1});

            dp[i][j] = dp[i - 1][j - 1] + std::min(tpA, tpB) * a;
        }
    }

    int ans = INF;
    for (int i = 0; i <= d; i++)
        ans = std::min(ans, dp[n][i]);

    std::cout << ans << "\n";
}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
