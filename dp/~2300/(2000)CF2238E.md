# E. Cake Trial

[Problem - E - Codeforces](https://codeforces.com/contest/2238/problem/E)

## 思路

考虑将 $N$ 替换完后，$Chell$ 选择子段的方式。实际上，将 $F$ 看作 $1$，$T$ 看作 $-1$，$Chell$ 选择序列的最大子段和的子段，答案最小。

考虑维护这样一个状态：处理完前 $i$ 个字符后，当前被记录成错误的数量 $j$ ，且考虑的最优结尾子段中 $F$ 比 $T$ 多 $k$ 的情况下，最大子段和的最小值是 $dp{_i}{_j}{_k}$。

因为另外一个人的目标是最大化答案，而一个状态的答案是 $j + k - dp{_i}{_j}{_k}$（相当于舍弃当前结尾子段，选择最大子段和子段），所以我们要维护最小值。

然后是代码转移的方法：

如果字符是 "T"：那么可能接到当前子段后面，可能是还不存在子段(长度为 0)。

如果字符是 "F"：那么一定接到当前字段后面最优。

这样一来，我们在满足最大子段和的情况下更新每种状态下最大子段和的最小值，最后对所有状态取 $max$，就能得到答案了。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n;
    std::cin >> n;
    std::string s;std::cin >> s;
    s = " " + s;
    std::vector dp(n + 1,std::vector<int>(n + 1,inf));
    dp[0][0] = 0;
    for(int i = 0;i < n;i++)
    {
        std::vector ndp(n + 1,std::vector<int>(n + 1,inf));
        char nx = s[i + 1];
        if(nx == 'T' || nx == 'N')
        {
            for(int j = 0;j <= n;j++)
            {
                if(dp[j][0] != inf)
                    ndp[j][0] = std::min(ndp[j][0],dp[j][0]);
                if(j + 1 <= n)
                    for(int k = 1;k <= n;k++)
                        if(dp[j][k] != inf)
                            ndp[j + 1][k - 1] = std::min(ndp[j + 1][k - 1],dp[j][k]);  
            }
            
        }
        if(nx == 'F' || nx == 'N')
        {
            for(int j = 0;j <= n;j++)
                for(int k = 0;k < n;k++)
                    if(dp[j][k] != inf)
                        ndp[j][k + 1] = std::min(ndp[j][k + 1],std::max(dp[j][k],k + 1));
        }
        dp = std::move(ndp);
    }
    int ans = 0;
    for(int i = 0;i <= n;i++)
    {
        for(int j = 0;j <= n;j++)
        {
            if(dp[i][j] == inf)continue;
            ans = std::max(ans,i - (dp[i][j] - j));
        }
    }
    std::cout << ans << "\n";

}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
