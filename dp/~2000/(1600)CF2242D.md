# D. Two Digit Strings

[Problem - 2242D - Codeforces](https://codeforces.com/problemset/problem/2242/D)

## 思路

很显然的一个结论是，首先字符串 $a$ 每位数字和模 $10$ 要等于 $b$ 的。

首先匹配的状态最多 $10$ 种：模数 $0$ ~ $9$，从最低位开始匹配，从起点到每个终点，这样的每一段都有一个状态，我们贪心的每次匹配每种状态中长度最小的段：因为后面的段都可以拆成这个最小的段 + 模数为 $0$ 的一个段，而模数为 $0$ 的段可以随意合并到前面段上，所以这样操作不会更劣。

但是考虑到这样匹配完后可能会出现一个字符串被匹配完，另外一个剩下的部分模数为 $0$ 的情况，$dp[n][m]$ 位置的值可能无法被更新到。所以我们对每次答案都做一次更新即可：对于 $dp[i][j]$，如果 $i != n$,$j != m$，此位置的答案是 $dp[i][j] + 1$，否则是 $dp[i][j]$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    std::string a,b;
    std::cin >> a >> b;
    std::reverse(a.begin(),a.end());
    std::reverse(b.begin(),b.end());
    int n = a.size(),m = b.size();
    a = " " + a;
    b = " " + b;
    std::vector mna(n + 1,std::vector<int>(10));
    std::vector mnb(m + 1,std::vector<int>(10));

    for(int st = 1;st <= n;st++)
    {
        for(int r = st,now = 0;r <= n;r++)
        {
            now = (now + a[r] - '0') % 10;
            if(!mna[st][now])mna[st][now] = r;
        }
    }
    for(int st = 1;st <= m;st++)
    {
        for(int r = st,now = 0;r <= m;r++)
        {
            now = (now + b[r] - '0') % 10;
            if(!mnb[st][now])mnb[st][now] = r;
        }
    }
    std::vector<int>sufa(n + 2),sufb(m + 2);
    for(int i = n;i >= 1;i--)sufa[i] = (sufa[i + 1] + (a[i] - '0')) % 10;
    for(int i = m;i >= 1;i--)sufb[i] = (sufb[i + 1] + (b[i] - '0')) % 10;
    std::vector dp(n + 1,std::vector<int>(m + 1,-INF));
    dp[0][0] = 0;
    for(int l = 0;l < n;l++)
        for(int r = 0;r < m;r++)
            for(int k = 0;k < 10;k++)   
                if(mna[l + 1][k] && mnb[r + 1][k])
                {
                    int L = mna[l + 1][k],R = mnb[r + 1][k];
                    dp[L][R] = std::max(dp[L][R],dp[l][r] + 1);
                }
    int ans = -INF;
    for(int l = 0;l <= n;l++)
        for(int r = 0;r <= m;r++)
            if(!sufa[l + 1] && !sufb[r + 1])
                ans = std::max(ans,dp[l][r]);
    if(ans <= 0)std::cout << "-1\n";
    else std::cout << ans << "\n";
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
