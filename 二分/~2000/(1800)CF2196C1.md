# C1. Interactive Graph (Simple Version)

[Problem - C1 - Codeforces](https://codeforces.com/contest/2196/problem/C1)

## 思路

找到当前起点，如果有出边，下一个路径一定是其最小的出边，将其放入答案中，此时后面有一段连续路径全是以这条边开始的，可以二分找到结束点。此时下一个路径要么为空，要么起点变成下一个节点，要么为当前节点下一条出边。那么可以通过这种方式找完所有边。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
void solve()
{
    int n;std::cin >> n;
    auto query = [&](int k) -> std::vector<int>
    {
        std::cout << "? " <<  k << std::endl;
        int q;std::cin >> q;
        if(q == -1)exit(0);
        std::vector<int>ans({});
        for(int i = 1;i <= q;i++)
        {
            int x;std::cin >> x;
            ans.push_back(x);
        }
        return ans;
    };
    std::vector<pii>edge;
    for(int l = 1;;l++)
    {
        std::vector<int>st = query(l),ed;
        while(st.size() == 1)st = query(++l);
        if(st.empty())break;
        int r = inf;
        while(l + 1 != r)
        {
            int mid = (l + r) >> 1;
            ed = query(mid);
            if(ed.size() >= 2  && (ed[0] == st[0] && st[1] == ed[1]))l = mid;
            else r = mid;
        }
        edge.push_back({st[0],st[1]});
    }
    std::cout << "! " << edge.size() << std::endl;
    for(auto [u,v] : edge)
        std::cout << u << " " << v << std::endl;
}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
