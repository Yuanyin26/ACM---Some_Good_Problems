# D. Slimes

[Problem - D - Codeforces](https://codeforces.com/contest/1923/problem/D)

## 思路

对于一个下标 $i$，只需要找到与其相邻的一个最短子段，满足子段和大于 $a[i]$ 且该子段中存在不同的两个数。

预处理前缀和数组和代表最近不同数下标的数组。很显然这两个数组都是递增的，我们可以依靠二分分别找到最小的合法位置下标，二者取 $max$ 即可。

上述操作正反做一遍，就可以得到答案了。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n;std::cin >> n;
    std::vector<int>a(n + 1),ans(n + 1,inf);
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    auto work = [&]() -> void
    {
        std::vector<int>pre(n + 1),mndiff(n + 1);
        for(int i = 1;i <= n;i++)
        {
            pre[i] = pre[i - 1] + a[i];
            if(a[i] == a[i - 1])mndiff[i] = mndiff[i - 1];
            else mndiff[i] = i - 1;
        }
        for(int i = 1;i < n;i++)
        {
            if(a[i + 1] > a[i])ans[i] = 1;
            else
            {
                int pos1 = std::upper_bound(pre.begin() + 1,pre.end(),a[i] + pre[i]) - pre.begin();
                int pos2 = std::upper_bound(mndiff.begin() + 1,mndiff.end(),i) - mndiff.begin();
                int pos = std::max(pos1,pos2);
                if(pos <= n)ans[i] = std::min(ans[i],pos - i);
            }
        }
    };
    work();
    std::reverse(a.begin() + 1,a.end());
    std::reverse(ans.begin() + 1,ans.end());
    work();
    for(int i = n;i >= 1;i--)
        std::cout << (ans[i] == inf ? -1 : ans[i]) << " \n"[i == 1];
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
