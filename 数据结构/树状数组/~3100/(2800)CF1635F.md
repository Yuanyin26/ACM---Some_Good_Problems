# F. Closest Pair

[Problem - F - Codeforces](https://codeforces.com/contest/1635/problem/F)

## 思路

设最优点对为 $$i<j$$，代价为

$$
(x_j-x_i)(w_i+w_j).
$$

若 $$w_i\le w_j$$，若在 $$i,j$$ 之间存在一个更靠近 $$j$$ 的点 $$k$$ 满足 $$w_k\le w_j$$，那么用 $$(k,j)$$ 替代后距离更短、权值和也不更大，原点对不可能最优。此时 $$i$$ 必须是 $$j$$ 左侧最近的、满足权值不大于 $$w_j$$ 的位置。$$w_i>w_j$$ 时完全对称，$$j$$ 必须是 $$i$$ 右侧最近的、权值不大于 $$w_i$$ 的位置。

所以真正可能成为答案的点对只有 $$O(n)$$ 个。用两次单调栈分别求每个点左侧、右侧最近的“不大于自身权值”的位置，即可生成全部候选对。询问 $$[L,R]$$ 只需要取所有满足

$$
L\le l<r\le R
$$

的候选代价最小值。我们可以离线处理这个过程，用树状数组维护后缀最小值或者线段树维护即可。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 3e5 + 7;
constexpr int P = 998244353;
struct finwick
{
    std::vector<int>t;
    int n;
    finwick(int len)
    {
        init(len);
    }
    void init(int len)
    {
        n = len;
        t.resize(n + 1,INF);
    }
    int lowbit(int x)
    {
        return x & (-x);
    }
    void add(int x,int k)
    {
        for(int i = x;i >= 1;i -= lowbit(i))
            t[i] = std::min(t[i],k);
    }
    int query(int l)
    {
        int ans = INF;
        for(int i = l;i <= n;i += lowbit(i))
            ans = std::min(ans,t[i]);
        return ans;
    }
};
std::vector<pii> G[N];
void solve()
{
    int n,q;
    std::cin >> n >> q;
    finwick fi(n);
    std::vector<int>X(n + 1),W(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> X[i] >> W[i];
    auto calc = [&](std::vector<int> &x,std::vector<int> &w,bool op) -> void
    {
        std::stack<int>stk;
        for(int i = 1;i <= n;i++)
        {
            while(!stk.empty() && w[stk.top()] > w[i])stk.pop();
            if(!stk.empty())
            {
                int j = stk.top();
                int W = std::llabs(x[j] - x[i]) * (w[i] + w[j]);
                if(!op)G[i].push_back({stk.top(),W});
                else G[n - stk.top() + 1].push_back({n - i + 1,W});
            }
            stk.push(i);
        }
    };
    calc(X,W,0);
    std::reverse(X.begin() + 1,X.end());
    std::reverse(W.begin() + 1,W.end());
    calc(X,W,1);
    std::vector<std::array<int,3>>que(q + 1);
    for(int i = 1;i <= q;i++)
    {
        int l,r;std::cin >> l >> r;
        que[i] = {r,l,i};
    }
    std::sort(que.begin() + 1,que.end());
    std::vector<int>ans(q + 1);
    for(int i = 1,p = 1;i <= q;i++)
    {
        auto [r,l,ind] = que[i];
        while(p <= r)
        {
            for(auto [pos,W] : G[p])fi.add(pos,W);
            p++;
        }
        ans[ind] = fi.query(l);
    }
    for(int i = 1;i <= q;i++)
        std::cout << ans[i] << "\n";
    
}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
