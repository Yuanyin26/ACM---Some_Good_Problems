# C. Tyler and Strings

[Problem - C - Codeforces](https://codeforces.com/problemset/problem/1648/C)

## 思路

要求统计由多重集合 $$s$$ 的元素组成的不同排列中，字典序严格小于 $$t$$ 的个数。

设当前还剩 $$res$$ 个元素，各值出现次数为 $$c_x$$。当前多重集合的不同排列数为

$$
W=\frac{res!}{\prod_x c_x!}.
$$

从左到右保持前缀与 $$t$$ 相同。处理 $$t_i$$ 时，如果当前位置选择任意 $$x<t_i$$，后面随意排列，一定得到更小的序列。设剩余元素中**小于** $$t_i$$ 的数量为 $$less$$，则这一位产生的贡献为

$$
W\cdot \frac{less}{rem}.
$$

用树状数组维护各值剩余出现次数，即可 $$O(\log n)$$ 求 $$less$$。

若 $$c_{t_i}=0$$，无法继续保持相同前缀，直接结束；否则固定这一位为 $$t_i$$，排列数更新

$$
W\leftarrow W\cdot \frac{c_{t_i}}{rem},
$$

随后更新树状数组。若 $$s$$ 的所有元素都用完且仍完整匹配了 $$t$$ 的前缀，因为短序列字典序更小，还要额外加 $$1$$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 2e5 + 7;
constexpr int P = 998244353;
int fa[N],infa[N];
int qmi(int a,int b)
{
    int res = 1;
    while(b)
    {
        if(b & 1)res = res * a % P;
        b >>= 1;
        a = a * a % P;
    }
    return res;
}
void init()
{
    fa[0] = 1;
    for(int i = 1;i < N;i++)fa[i] = fa[i - 1] * i % P;
    infa[N - 1] = qmi(fa[N - 1],P - 2);
    for(int i = N - 1;i >= 1;i--)infa[i - 1] = infa[i] * i % P;
}
struct finwick
{
    std::vector<int>t;
    int n;
    finwick(int len)
    {
        init(len);
    }
    void init(int len)
    {
        n = len;
        t.resize(n + 1);
    }
    int lowbit(int x)
    {
        return x & (-x);
    }
    void add(int x,int k)
    {
        for(int i = x;i <= n;i += lowbit(i))
            t[i] += k;
    }
    int query(int l,int r)
    {
        if(l > r)return 0;
        int ans = 0;
        for(int i = r;i >= 1;i -= lowbit(i))
            ans += t[i];
        for(int i = l - 1;i >= 1;i -= lowbit(i))
            ans -= t[i];
        return ans;
    }
};
finwick fi = finwick(N);
void solve()
{
    int n,m;
    std::cin >> n >> m;
    std::vector<int>s(n + 1),t(m + 1);
    for(int i = 1;i <= n;i++)
    {
        std::cin >> s[i];
        fi.add(s[i],1);
    }
    for(int i = 1;i <= m;i++)std::cin >> t[i];
    int sum = fa[n];
    for(int i = 1;i < N;i++)
        sum = sum * infa[fi.query(i,i)] % P;
    int ans = 0;
    for(int i = 1;i <= m;i++)
    {
        int tmp = fi.query(1,t[i] - 1),inv = qmi(n - i + 1,P - 2);
        ans = (ans + sum * tmp % P * inv % P) % P;
        int res = fi.query(t[i],t[i]);
        sum = sum * res % P * inv % P;
        if(!sum)
        {
            if(i > n)ans = (ans + 1) % P;
            break;
        }
        fi.add(t[i],-1);
    }
    std::cout << ans << "\n";

}
signed main()
{
    init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
