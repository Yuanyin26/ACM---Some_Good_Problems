# F. Large Graph

[Problem - F - Codeforces](https://codeforces.com/contest/1978/problem/F)

## 思路

矩阵沿每条主对角线方向的值完全相同，因此先按差值 $$d=j-i$$ 把 $$n^2$$ 个点压成 $$2n-1$$ 条对角线。

若某条对角线上的值 $$x>1$$，同一对角线相邻两个格子的曼哈顿距离为 $$2\le k$$，且 $$\gcd(x,x)>1$$，因此整条对角线内部连通，可以缩成一个点。若 $$x=1$$，它与任何点的 gcd 都是 $$1$$，所以该对角线上的每个格子都是独立连通块，直接累加其长度。

两条对角线 $$d_1,d_2$$ 之间的最小曼哈顿距离恰好为 $$|d_1-d_2|$$。因此两个值都大于 $$1$$ 的对角线能够直接连边，当且仅当

$$
|d_1-d_2|\le k,\qquad \gcd(x_{d_1},x_{d_2})>1.
$$

将每个数分解质因子。对每个质数 $$p$$，按照 $d$ 排序对含有质因子 $p$ 的对角线进行枚举。若相邻两个出现位置之差不超过 $$k$$，就用并查集合并。

最终答案为所有 $$x>1$$ 对角线的 DSU 连通块数量，加上所有值为 $$1$$ 的对角线所贡献的独立格子数。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 1e6 + 7;
constexpr int P = 998244353;
//筛素数
std::vector<int>pri;
bool vis[N];
int minp[N];//存数的最小质因子
void init()
{
    for(int i = 2;i < N;i++)
    {
        if(!vis[i]){pri.push_back(i);minp[i] = i;}
        for(auto x : pri)
        {
            if(i * x >= N)break;
            vis[i * x] = 1;
            minp[i * x] = x;
            if(i % x == 0)break;
        }
    }
}
std::vector<pii> ind[N];
struct dsu
{
    std::vector<int>fa,siz;
    int n;
    dsu(int len)
    {
        n = len;
        fa.resize(n + 1);
        siz.resize(n + 1,1);
        for(int i = 1;i <= n;i++)fa[i] = i;
    }
    int find(int x)
    {
        if(x == fa[x])return x;
        return fa[x] = find(fa[x]);
    }
    void merge(int a,int b)
    {
        a = find(a);
        b = find(b);
        if(a == b)return;
        if(siz[a] > siz[b])std::swap(a,b);
        siz[a] += siz[b];
        fa[b] = a;
    }
};
void solve()
{
    int n,k;
    std::cin >> n >> k;
    std::vector<int>a(n + 1);
    std::set<int>s;//pri
    int ans = 0;
    for(int i = 1;i <= n;i++)
    {
        std::cin >> a[i];
        if(a[i] == 1)ans += n - 2 + (i == 1);
        while(a[i] != 1)
        {
            int p = minp[a[i]];
            s.insert(p);
            ind[p].push_back({1 - i,i});
            if(i != 1)ind[p].push_back({n - i + 1,i + n - 1});
            while(minp[a[i]] == p)a[i] /= p;
        }
    }
    dsu ds(2 * n - 1);
    for(int v : s)
    {
        std::sort(ind[v].begin(),ind[v].end());
        int len = ind[v].size();
        for(int i = 1;i < len;i++)
        {
            int dert = std::llabs(ind[v][i].first - ind[v][i - 1].first);
            if(dert <= k)ds.merge(ind[v][i].second,ind[v][i - 1].second);
        }
        ind[v].clear();
    }
    for(int i = 1;i <= 2 * n - 1;i++)
        if(i == ds.find(i))ans++;
    std::cout << ans << "\n";
}
signed main()
{
    init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
