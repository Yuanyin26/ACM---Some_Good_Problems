# F. Two Subarrays

[Problem - 2042F - Codeforces](https://codeforces.com/problemset/problem/2042/F)

## 思路

从左到右扫描一个区间时，关于“两段不相交非空子数组”只需要记录当前处于哪一个阶段：

$$
0:\text{第一段之前},\quad
1:\text{第一段内部},\quad
2:\text{两段之间},\quad
3:\text{第二段内部},\quad
4:\text{第二段之后}.
$$

因此每个线段树节点维护一个 $$5\times5$$ 的矩阵 $$M$$，其中 $$M_{i,j}$$ 表示从阶段 $$i$$ 进入该区间，离开时处于阶段 $$j$$ 所能取得的最大贡献。

叶子位置 $$x$$ 的转移：跳过该点；以它作为某一段的左端点；继续当前子数组；以它作为右端点；或者让长度为 $$1$$ 的子数组在该点同时开始并结束。根据题目代价，开始/结束时加入对应的 $$b_x$$，位于子数组内部时加入 $$a_x$$。

两个相邻区间合并就是：

$$
C_{i,k}=\max_j(A_{i,j}+B_{j,k}).
$$

因为状态数只有 $$5$$，一次合并是常数级别。区间询问得到的矩阵中 $$M_{0,4}$$ 就是完整选出两段后的最大值，单点修改只需重建一个叶子。

复杂度 $$O(5^3\log n)$$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 2e5 + 7;
constexpr int P = 998244353;
using mat = std::vector<std::vector<int>>;
struct node
{
    int l;
    int r;
    mat dp;
}t[N << 2];
mat calc(int x,int y)
{
    mat dp(5,std::vector<int>(5,-INF));
    dp[0][0] = dp[2][2] = dp[4][4] = 0;
    dp[1][1] = dp[3][3] = x;
    dp[0][1] = dp[1][2] = dp[2][3] = dp[3][4] = x + y;
    dp[0][2] = dp[2][4] = x + 2 * y;
    return dp;
};
mat merge(mat x,mat y)
{
    if(x.empty())return y;
    mat dp(5,std::vector<int>(5,-INF));
    for(int i = 0;i < 5;i++)
        for(int k = i;k < 5;k++)
            for(int j = k;j < 5;j++)
                dp[i][j] = std::max(dp[i][j],x[i][k] + y[k][j]);
    return dp;
};
void push_up(int p)
{
    t[p].dp = merge(t[p << 1].dp,t[p << 1 | 1].dp);
}
int a[N],b[N];
void build(int p,int l,int r)
{
    t[p] = {l,r};
    if(l == r)
    {
        t[p].dp = calc(a[l],b[l]);
        return;
    }
    int mid = (l + r) >> 1;
    build(p << 1,l,mid);
    build(p << 1 | 1,mid + 1,r);
    push_up(p);
}
void update(int p,int pos,int x,int y)
{
    if(t[p].l == t[p].r && t[p].l == pos)
    {
        t[p].dp = calc(x,y);
        return;
    };
    int mid = (t[p].l + t[p].r) >> 1;
    if(pos <= mid)update(p << 1,pos,x,y);
    else update(p << 1 | 1,pos,x,y);
    push_up(p);
}
mat query(int p,int nl,int nr)
{
    if(nl <= t[p].l && t[p].r <= nr)return t[p].dp;
    int mid = (t[p].l + t[p].r) >> 1;
    mat dp;
    if(nl <= mid)dp = merge(dp,query(p << 1,nl,nr));
    if(nr > mid)dp = merge(dp,query(p << 1 | 1,nl,nr));
    return dp;
}
void solve()
{
    int n;
    std::cin >> n;
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    for(int i = 1;i <= n;i++)std::cin >> b[i];
    build(1,1,n);
    int q;std::cin >> q;
    while(q--)
    {
        int op,x,y;
        std::cin >> op >> x >> y;
        if(op == 3)
        {
            mat ans = query(1,x,y);
            std::cout << ans[0][4] << "\n";
        }
        else
        {
            if(op == 1)a[x] = y;
            else b[x] = y;
            update(1,x,a[x],b[x]);
        }
    }

}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
