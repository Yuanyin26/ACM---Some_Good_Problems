# F. Vessels, Heights and Two Versions (Hard Version)

[Problem - F - Codeforces](https://codeforces.com/contest/2234/problem/F)

## 思路

首先将 $h$ 看作边，考虑当前起点 $s(w_s = 0)$ 到另外一个节点 $v$ ，设一条 $s \rightarrow v$ 的简单路径上最大边权值为 $mx$ ，那么 $w_v \le mx$ 。因为如果 $w_v \gt mx$ ，那么所有节点的 $w$ 值都必须要相等，而 $w_s = 0$，则矛盾。此时当我们同时取到上界时，是合法的，所以我们找到了最大值的构造方法。

$s \rightarrow v$ 的路径有两条，其中一定有一条经过最长的边，我们将这条边删掉，两端即为我们考虑的数组两端。此时每个点对于一个起点，只需要考虑一条边即可。使用单调栈计算答案。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 1e7 + 7;
constexpr int P = 1e9 + 7;
void solve()
{
    int n;std::cin >> n;
    std::vector<int>a(n);
    int ex = 0;
    for(int i = 0;i < n;i++)
    {
        std::cin >> a[i];
        if(a[ex] < a[i])ex = i;
    }
    ex = n - 1 - ex;
    std::vector<int>arr(n);
    for(int i = 0;i < n;i++)arr[i] = a[(i - ex + n) % n];
    std::vector<int>ansl(n),ansr(n);
    auto work = [&](std::vector<int> &h,std::vector<int> &ans) -> void
    {
        std::stack<pii>stk;
        stk.push({-1,inf});
        int sum = 0;
        for(int i = 0;i < n - 1;i++)
        {
            while(!stk.empty() && stk.top().second <= h[i])
            {
                auto [r,w] = stk.top();
                stk.pop();
                sum -= (r - stk.top().first) * w;
            }
            sum += (i - stk.top().first) * h[i];
            stk.push({i,h[i]});
            ans[i + 1] += sum; 
        }   
    };
    work(arr,ansl);
    std::reverse(arr.begin(),arr.begin() + n - 1);
    work(arr,ansr);
    std::reverse(ansr.begin(),ansr.begin() + n);
    for(int i = 0;i < n;i++)
        std::cout << ansl[(i + ex) % n] + ansr[(i + ex) % n] << " \n"[i == n - 1];

}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
