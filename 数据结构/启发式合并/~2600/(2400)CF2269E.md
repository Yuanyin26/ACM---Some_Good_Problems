# E. KiaKio and Energy Intervals

[Problem - E - Codeforces](https://codeforces.com/contest/2269/problem/E)

## 思路

结果式子我们可以先求异或和 $sum$ 然后在对 $sum$ 做与运算。

实际上是在更新一个掩码，那么每一位实际上是独立的。我们贪心的从高位到低位判断是否能放置 $1$。

此时有候选答案 $M$，目的是找到一个长度大于等于 $2$ 的区间使得异或和是 $M$ 的超集。

所以我们可以只考虑 $M$ 上为 $1$ 的位置，区间异或和使用前缀和预处理，对于一个端点的前缀异或 $S_r = Pre_r$ & $M$，如果存在一个 $l$ 使得 $S_{l - 1} $ ^ $S_r == M$，且区间内最大值 $m$ 是 $M$ 的超集。 固定 $M$ 后，我们可以在笛卡尔树上做启发式合并，找到合法的配对点，判断其是否存在即可。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
// #define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 1e3 + 7;
constexpr int P = 1e9 + 7;
constexpr double eps = 1e-9;

void solve()
{
    int n;
    std::cin >> n;
    std::vector<int>a(n + 1),pre(n + 1);
    for(int i = 1;i <= n;i++)
    {
        std::cin >> a[i];
        pre[i] = pre[i - 1] ^ a[i];
    }
    std::vector<int>ls(n + 1),rs(n + 1),siz(n + 1);
    std::stack<int>stk;
    for(int i = 1;i <= n;i++)
    {
        int le = 0;
        while(!stk.empty() && a[stk.top()] <= a[i])
        {
            le = stk.top();
            stk.pop();
        }
        if(!stk.empty())rs[stk.top()] = i;
        ls[i] = le;
        stk.push(i);
    }
    int rt = 0;
    while(!stk.empty()){rt = stk.top();stk.pop();}
    auto dfs1 = [&](auto &&self,int u) -> void
    {
        siz[u] = 1;
        for(int v : {ls[u],rs[u]})
        {
            if(!v)continue;
            self(self,v);
            siz[u] += siz[v];
        }
    };
    dfs1(dfs1,rt);
    std::vector<int>s(n + 1),cnt(1LL << 18);int M,ok;
    auto dfs = [&](auto &&self,int u,int op) -> void
    {
        if(!u)return;
        int sum = 0;
        if(siz[ls[u]] > siz[rs[u]])
        {
            self(self,rs[u],0);
            self(self,ls[u],1);
            cnt[s[u - 1 - siz[ls[u]]]]++;
            for(int i = u;i <= u + siz[rs[u]];i++)
                sum += cnt[s[i] ^ M];
            if((s[u - 1] ^ s[u]) == M)sum--;
            cnt[s[u - 1 - siz[ls[u]]]]--;
            if(op)for(int i = u;i <= u + siz[rs[u]];i++)cnt[s[i]]++;
            else for(int i = 1;i <= siz[ls[u]];i++)cnt[s[u - i]]--;
        }
        else
        {
            self(self,ls[u],0);
            self(self,rs[u],1);
            cnt[s[u]]++;
            for(int i = 1;i <= siz[ls[u]];i++)
                sum += cnt[s[u - i] ^ M];
            sum += cnt[s[u - 1 - siz[ls[u]]] ^ M];
            if((s[u - 1] ^ s[u]) == M)sum--;

            if(!op)for(int i = u;i <= u + siz[rs[u]];i++)cnt[s[i]]--;
            else for(int i = 1;i <= siz[ls[u]];i++)cnt[s[u - i]]++;
        }

        if((a[u] & M) == M && sum)ok = 1;
    };
    int ans = 0;
    for(int i = 17;i >= 0;i--)
    {
        ok = 0;
        M = ans | (1LL << i);
        for(int i = 1;i <= n;i++)s[i] = pre[i] & M;
        dfs(dfs,rt,0);
        if(ok)ans |= 1LL << i;
    }
    std::cout << ans << "\n";
    
}
signed main()
{
	// init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
