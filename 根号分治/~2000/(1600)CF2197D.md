# D. Another Problem about Beautiful Pairs

[Problem - D - Codeforces](https://codeforces.com/contest/2197/problem/D)

## 思路

首先 $a_i,a_j$ 不会同时同时大于 $\sqrt{n}$ ，在我枚举到 $i$ 时，考虑 $a_i$ 的大小，如果大于 $\sqrt{n}$，将 $a_i$ 作为左端点或者右端点，枚举另一个权值，然后判断是否合法即可；

如果小于等于 $\sqrt{n}$，那就将其作为 $j$，向左枚举其另一个权值，且小于等于 $\sqrt{n}$ 即可。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
void solve()
{
    int n;std::cin >> n;
    std::vector<int>a(n + 1);
    int B = std::sqrt(n);
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    int ans = 0;
    for(int ind = 1;ind <= n;ind++)
    {
        if(a[ind] <= B)
        {
            int j = ind,aj = a[ind];
            for(int ai = 1;ai <= B && ai * aj < j;ai++)
            {
                int i = j - ai * aj;
                if(a[i] == ai)ans++;
            }
        }
        else
        {
            for(int x = 1;x * a[ind] <= n;x++)
            {
                int i = ind - x * a[ind];
                int j = ind + x * a[ind];
                if(i >= 1 && a[i] == x)ans++;
                if(j <= n && a[j] == x)ans++;
            }
        }
    }
    std::cout << ans << "\n";

}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
