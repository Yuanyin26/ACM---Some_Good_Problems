# **E - Young Maids**

[E - Young Maids](https://atcoder.jp/contests/arc080/tasks/arc080_c)

## 思路

考虑某个当前仍独立存在的区间 $$[l,r]$$。由于每次删除的是相邻两个数，最终这个区间贡献到答案中的第一个二元组，一定由一个与 $$l$$ 同奇偶的位置 $$i$$ 和其右侧一个异奇偶位置 $$j$$ 组成。

为了使最终序列字典序最小，我们贪心的找到区间中与 $$l$$ 同奇偶位置上的最小值 $$p_i$$，再在 $$[i + 1,r]$$ 中取另一种奇偶位置上的最小值 $$p_j$$。这就是该区间当前能够贡献的最优二元组。

分别对奇、偶位置建立 $ST$ 表，可以 $$O(1)$$ 求区间最小值及其位置。所有当前区间的候选二元组放入小根堆，每次取全局字典序最小的一对 $$(p_i,p_j)$$ 加入答案。

取出以后，原区间被拆成

$$
[l,i - 1],\quad [i + 1,j - 1],\quad [j + 1,r]
$$

对所有非空子区间重新计算并加入堆。每个位置只被取出一次，因此总复杂度 $$O(n\log n)$$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 2e5 + 7;
constexpr int P = 998244353;

void solve()
{
    int n;std::cin >> n;
    std::vector<int>a(n + 1),pos(n + 1);
    std::vector st(2,std::vector (n + 1,std::vector<int>(21,inf)));
    for(int i = 1;i <= n;i++)
    {
        std::cin >> a[i];
        pos[a[i]] = i;
        st[i & 1][i][0] = a[i];
    }
    for(int t = 0;t < 2;t++)
        for(int j = 1;j < 21;j++)
            for(int i = 1;i + (1LL << j) - 1 <= n;i++)
                st[t][i][j] = std::min(st[t][i][j - 1],st[t][i + (1LL << j - 1)][j - 1]);
    std::priority_queue<std::array<int,4>>que;
    auto query = [&](int t,int l,int r) -> int
    {
        if(l > r)return 0;
        int k = std::__lg(r - l + 1);
        return std::min(st[t][l][k],st[t][r - (1LL << k) + 1][k]);
    };
    auto calc = [&](int l,int r) -> pii
    {
        int a1 = query(l & 1,l,r);
        int a2 = query((l & 1) ^ 1,pos[a1] + 1,r);
        return {a1,a2};
    };
    auto add = [&](int l,int r) -> void
    {
        if(l < r)
        {
            auto [t1,t2] = calc(l,r);
            que.push({-t1,-t2,l,r});
        }
    };
    add(1,n);
    std::vector<int>ans;
    while(!que.empty())
    {
        auto [w1,w2,l,r] = que.top();que.pop();
        w1 = -w1,w2 = -w2;
        ans.push_back(w1);ans.push_back(w2);
        int x = pos[w1],y = pos[w2];
        add(l,x - 1);
        add(x + 1,y - 1);
        add(y + 1,r);
    }
    for(int i = 0;i < n;i++)
        std::cout << ans[i] << " \n"[i == n - 1];

}
signed main()
{
    // init();
    IOS;
    int T = 1;//std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
