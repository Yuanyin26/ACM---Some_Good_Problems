# C. 魔法审判

[魔法审判 - 题目 - QOJ.ac](https://qoj.ac/contest/3945/problem/19015)

## 思路

考虑倒着来做这个题目。

设目前存活人的集合为 $S$。一开始只有 $s$ 存活。此时想复活 $u$，就必须使其目前能积累的最大可疑度 $w_u$ 与下标组成二元组 $[w_u,u]$ 的大于等于 $max_{i \in S}[a_i,i]$。

考虑一个贪心过程：对于当前可复活的人的集合中，选择 $[a_i,i]$ 最小的那个人复活是最优的，这个过程用小根堆维护。

证明：

如果 $[a_i,i]$ 没有成为存活人集合中最大的二元组，其对未复活的人没有负向贡献；

如果成为了最大二元组，首先其不会影响到目前可复活集合中的人，因为他们的二元组不需要增加可疑度，都比 $[a_i,i]$ 要高；其次对于目前不在复活集合中的人，如果其想要复活，对于其想复活时 $S$ 的最大二元组，一定不小于 $[a_i,i]$。所以这个二元组也不会对这些人产生负面影响。

那么我们选择复活的人之后，将其对每个尚未复活的人的可疑度最大贡献更新给该人累积的最大可疑度，如果这个人满足了目前可复活的条件，放入小根堆。

直到小根堆为空时，判断一下是否所有人都被复活了即可。

有一个细节就是，自己对自己的指控需要提前加入累积的可疑度，因为在其死之前还活着。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
int MAX[N];
void solve()
{
    int n,m,s;
    std::cin >> n >> m >> s;
    std::vector<int>a(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> a[i];
    std::vector<std::vector<pii>>g(n + 1);    
    std::vector<bool>vis(n + 1);
    std::vector<int>res(a);//积累的值
    std::priority_queue<pii>que;
    for(int i = 1;i <= m;i++)
    {
        int u,v,s;
        std::cin >> u >> v >> s;
        if(u == v)MAX[u] = std::max(MAX[u],s);
        else g[u].push_back({v,s});
    }
    pii now = {a[s],s};
    for(int i = 1;i <= n;i++)
    {
        res[i] += MAX[i];
        MAX[i] = 0;
        if(pii{res[i],i} >= now)
        {
            vis[i] = 1;
            que.push({-a[i],-i});
        }
    }
    while(!que.empty())
    {
        auto [sum,ind] = que.top();que.pop();
        sum = -sum,ind = -ind;
        now = std::max(now,pii{sum,ind});

        for(auto [v,s] : g[ind])
            MAX[v] = std::max(MAX[v],s);
        for(auto [v,s] : g[ind])
        {
            res[v] += MAX[v];
            MAX[v] = 0;
            if(!vis[v] && pii{res[v],v} >= now)
            { 
                que.push({-a[v],-v});
                vis[v] = 1;
            }
        }
    }
    if(std::count(vis.begin() + 1,vis.end(),1) == n)std::cout << "YES\n";
    else std::cout << "NO\n";

}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
