# E. Explosions?

[Problem - E - Codeforces](https://codeforces.com/problemset/problem/1795/E)

## 思路

枚举爆炸中心 $$i$$。若中心最终保留生命值 $$h_i$$，为了让爆炸向左连续传播，左侧生命值最多只能依次为

$$
h_i-1,h_i-2,\ldots
$$

同时不超过原生命值，且最低为 $$0$$。设 $$L_i$$ 为区间 $$[1,i]$$ 在这种限制下能保留的最大生命值总和，$$R_i$$ 同理。

计算 $$L_i$$ 时,枚举 $i$，维护 $$h_j-j$$ 单调栈。对当前 $$i$$，弹掉所有 $$h_j-j>h_i-i$$ 的位置。设最终能衔接到的位置为 $$j$$，并同时考虑等差下降到 $$0$$ 的边界 $$i-h_i$$，则当前新形成的一段长度为 $$len=i-j$$，贡献为

$$
len\cdot h_i-\frac{len(len-1)}2.
$$

如果栈中还有 $h_j - j <= h_i - i$ 且 $len \lt h_i$，加上 $L_j$。反转数组再做一次得到 $$R_i$$。

设原总生命值为 $$S$$。以 $$i$$ 为中心时，爆炸前需要用普通攻击削去的生命值为

$$
S-(L_i+R_i-h_i),
$$

爆炸本身需要 $$h_i$$ 次代价，因此总答案为

$$
S-L_i-R_i+2h_i.
$$

对所有中心取最小值即可。复杂度 $$O(n)$$。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
using ull = unsigned long long;
using ld = long double;
constexpr int N = 2e5 + 7;
constexpr int P = 998244353;

void solve()
{
    int n;std::cin >> n;
    std::vector<int>h(n + 1);
    for(int i = 1;i <= n;i++)std::cin >> h[i];
    int sum = std::accumulate(h.begin() + 1,h.end(),0LL);
    std::vector<int>L(n + 1),R(n + 1);
    auto calc = [&](std::vector<int> &arr) -> void
    {
        std::stack<pii>stk;
        stk.push({-inf,0});
        for(int i = 1;i <= n;i++)
        {
            int w = h[i] - i;
            while(!stk.empty() && stk.top().first > w)stk.pop();
            int len = i - std::max(i - h[i],stk.top().second);
            arr[i] = len * h[i] - len * (len - 1) / 2;
            if(stk.top().second > i - h[i])arr[i] += arr[stk.top().second];
            stk.push({w,i});
        }
    };
    calc(L);
    std::reverse(h.begin() + 1,h.end());
    calc(R);
    std::reverse(R.begin() + 1,R.end());
    std::reverse(h.begin() + 1,h.end());
    int ans = INF;
    for(int i = 1;i <= n;i++)
        ans = std::min(ans,sum - (L[i] + R[i] - h[i]) + h[i]);
    std::cout << ans << "\n";
}
signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
