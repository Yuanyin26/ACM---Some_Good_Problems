# D2. XOR Sorting (Hard Version)

[Problem - D2 - Codeforces](https://codeforces.com/contest/2247/problem/D2)

## 思路

我们先依照数组下标最高位二进制是否为 $1$ 来划分出左右两个子数组。那么这两个子数组下标在内部相互异或，这个最高位二进制一定是 $0$，如果数组间相互异或、则是 $1$。也就是说此时左右两个数组想要进行交换，$k$ 应该大于等于最高位代表的值。

也就是说，如果左数组的最大值大于右数组的最小值的话，此时两个数组需要进行交换，那我的 $k$ 就可以确定了；否则我们分别递归下去找即可，如果没找到说明无需排序。

对于更新而言，我们使用线段树维护，每次单点更新，也只涉及到一条链。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;
struct node
{
    int l;
    int r;
    int mx;
    int mn;
};

void solve()
{
    int n,q;
    std::cin >> n >> q;
    int depth = std::__lg(n - 1) + 1;
    int len = 1LL << depth;
    std::vector<int>a(len,inf);
    std::vector<node>t((len << 2) + 7);
    std::vector<int>cnt(depth);

    for(int i = 0;i < n;i++)std::cin >> a[i];
    auto push_up = [&](int p) -> void
    {
        t[p].mn = std::min(t[p << 1].mn,t[p << 1 | 1].mn);
        t[p].mx = std::max(t[p << 1].mx,t[p << 1 | 1].mx);
    };
    auto build = [&](auto &&self,int p,int dep,int l,int r) -> void
    {
        t[p] = {l,r,0,0};
        if(l == r)
        {
            t[p].mn = t[p].mx =  a[l];
            return;
        }
        int mid = l + (1LL << dep) - 1;
        self(self,p << 1,dep - 1,l,mid);
        self(self,p << 1 | 1,dep - 1,mid + 1,r);
        push_up(p);
        if(t[p << 1].mx > t[p << 1 | 1].mn)cnt[dep]++;;
    };
    build(build,1,depth - 1,0,len - 1);
    auto update = [&](auto &&self,int p,int dep,int pos,int k) -> void
    {
        if(t[p].l == t[p].r)
        {
            t[p].mn = t[p].mx = k;
            return;
        }
        if(t[p << 1].mx > t[p << 1 | 1].mn)cnt[dep]--;;
        int mid = (t[p].l) + (1LL << dep) - 1;
        if(pos <= mid)self(self,p << 1,dep - 1,pos,k);
        else self(self,p << 1 | 1,dep - 1,pos,k);
        push_up(p);
        if(t[p << 1].mx > t[p << 1 | 1].mn)cnt[dep]++;;
    };
    auto ans = [&]() -> int
    {
        for(int i = depth - 1;i >= 0;i--)
            if(cnt[i])return (1LL << i);
        return 0;
    };
    std::cout << ans() << "\n";
    while(q--)
    {
        int ind,x;
        std::cin >> ind >> x;
        update(update,1,depth - 1,ind,x);
        std::cout << ans() << "\n";
    }
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
