# E. Build a Tree

[Problem - E - Codeforces](https://codeforces.com/contest/2247/problem/E)

## 思路

首先对于任意一颗树，我们找到其重心，标记为根节点，并编号 $1$。

有公式 $dist(i,j) = dep[i] + dep[j] - 2 \times LCA(i,j)$，那对于一个形状不变的树，我只需要让任意 $LCA(i,i + 1)$ 等于根节点即可。

因为我们的根节点是重心，每个连通块的大小不超过 $\lfloor \frac{n}{2} \rfloor$，所以我们一定可以构造出 $LCA(i,i + 1)$ 都为 $0$ 情况，此时我们答案的上界就是最大深度和 $\times 2$。

又因为题目答案相当于是求 $1 -> 2 -> 3 ... -> n -> 1$ 的一个回路，每条边至少被经过两次，下界就是 $2 \times (n - 1)$，且答案一定是偶数。

那么我们从下界开始，并将奇偶分组，往上加深度即可。

## 代码

```c++
#include<bits/stdc++.h>
#define IOS std::ios::sync_with_stdio(0);std::cin.tie(0);std::cout.tie(0);
#define inf 0x3f3f3f3f
#define INF 4557430888798830399
#define int long long
using i64 = long long;
using ull = unsigned long long;
using i128 = __int128_t;
using pii = std::pair<int,int>;
constexpr int N = 1e6 + 7;
constexpr int P = 1e9 + 7;
using ull = unsigned long long;
using ld = long double;

void solve()
{
    int n,k;
    std::cin >> n >> k;
    if(k & 1)
    {
        std::cout << "-1\n";
        return;
    }
    int len[2] = {n >> 1,n - (n >> 1) - 1};
    int lo = 2 * (n - 1),up = len[0] * (len[0] + 1) + len[1] * (len[1] + 1);
    if(k < lo || k > up)
    {
        std::cout << "-1\n";
        return;
    }
    for(int dep = 0,la = 0;dep <= len[1];dep++)
    {
        int up = la + (len[0] + len[1] - dep * 2) * 2;
        if(k > up)
        {
            la = up;
            continue;
        }
        len[0] -= dep;len[1] -= dep;
        std::vector<pii>ans;
        for(int i = 1,la1 = 1,la2 = 1;i <= dep;i++)
        {
            ans.push_back({la1,i * 2 + 1});
            ans.push_back({la2,i * 2});
            la1 = i * 2 + 1;
            la2 = i * 2;
        }
        int cnt = (k - la) >> 1;
        for(int i = 1;i <= std::min(cnt,len[0]);i++)
            ans.push_back({std::max(1LL,dep * 2),(dep + i) * 2});
        for(int i = std::min(cnt,len[0]) + 1;i <= len[0];i++)
            ans.push_back({std::max(1LL,dep * 2 - 2),(dep + i) * 2});
        cnt -= std::min(cnt,len[0]);
        for(int i = 1;i <= std::min(cnt,len[1]);i++)
            ans.push_back({std::max(1LL,dep * 2 + 1),(dep + i) * 2 + 1});
        for(int i = std::min(cnt,len[1]) + 1;i <= len[1];i++)
            ans.push_back({std::max(1LL,dep * 2 - 1),(dep + i) * 2 + 1});
        for(auto [u,v] : ans)
            std::cout << u << " " << v << "\n";
        return;
    }
        
        
}

signed main()
{
    // init();
    IOS;
    int T = 1;std::cin >> T;
    while(T--)
    {
        solve();
    }
    return 0;
}
```
